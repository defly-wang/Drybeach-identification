# 干滩识别系统 (Dry Beach Identification System)

基于Python和PyQt6的计算机视觉系统，用于水面分界线与坝体识别。

## 功能特性

- **视频帧提取**: 从视频文件按指定间隔截取图片
- **水线检测**: 基于边缘检测的水线自动识别
- **标记分割**: 标注水面、滩面、分界线、坝体区域，支持多边形绘制
- **模型训练**: CNN分类模型训练，支持增量训练
- **图像识别**: 滑动窗口 + CNN分类识别
- **生成分界线**: 从识别结果自动生成平滑的分界线
- **距离校准**: 像素距离与实际距离转换
- **PyQt6 GUI**: 友好的图形用户界面

## GUI使用说明

### 标签页顺序

1. **视频提取**: 从视频文件中提取帧图片
2. **水线检测**: 基于边缘检测自动识别水线
3. **标记分割**: 标注图像中的各类区域
4. **模型训练**: 训练CNN分类模型
5. **识别**: 使用训练好的模型识别图像
6. **校准**: 像素距离与实际距离转换校准

### 标记分割

1. 点击"打开图片"加载图像
2. 选择工具："面标记"绘制多边形区域
3. 选择类别：水面/滩面/分界线/坝体
4. 在图像上点击添加顶点，右键撤销，双击完成
5. 点击"图像分割"保存训练样本

### 模型训练

1. 在"标记分割"中导出训练数据
2. 切换到"模型训练"标签页
3. 点击"选择数据目录"，选择包含分类子目录的数据集
4. (可选) 选择续训模型进行增量训练
5. 设置训练参数
6. 点击"开始训练"
7. 训练完成后在识别标签页加载模型

### 识别流程

1. 点击"加载模型"选择训练好的模型(.pt文件)
2. 点击"打开图片"加载待识别图片
3. (可选) 设置识别区域
4. 设置切片尺寸、步长和置信度阈值
5. 点击"开始识别"
6. 点击"生成分界线"生成边界线
7. 保存结果

### 识别结果颜色

- **水面(water)**: 浅蓝色 (0, 200, 255)
- **滩面(beach)**: 黄绿色 (200, 255, 0)
- **分界线(boundary)**: 紫色 (255, 0, 255)
- **坝体(dam)**: 橙色 (0, 100, 255)
