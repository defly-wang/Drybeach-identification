# 干滩识别系统 (Dry Beach Identification System)

基于Python和PyQt6的计算机视觉系统，用于水面分界线与坝体识别。

## 功能特性

- **视频帧提取**: 从视频文件按指定间隔截取图片
- **标记分割**: 标注水面、滩面、分界线、坝体区域，支持多种标注工具
- **模型训练**: 使用YOLO模型训练，支持water/beach/boundary/dam四分类
- **滑动窗口识别**: 基于训练好的模型对图像进行区域分类
- **结果可视化**: 彩色叠加显示各类别区域
- **PyQt6 GUI**: 友好的图形用户界面

## GUI使用说明

### 标签页顺序

1. **视频提取**: 从视频文件中提取帧图片
2. **标记分割**: 标注图像中的各类区域
   - 支持多边形、线段、矩形、点标注
   - 分类目录: water(水面)、beach(滩面)、boundary(分界线)、dam(坝体)
   - 自动切分大图为训练样本
3. **模型训练**: 训练YOLO分类模型
   - 选择数据目录
   - 设置训练轮数
   - 自动划分训练集/验证集(80/20)
4. **识别**: 使用训练好的模型识别图像
   - 加载YOLO模型
   - 打开待识别图片
   - 设置切片尺寸和步长
   - 运行识别
5. **校准**: 像素距离与实际距离转换校准

### 标记分割

1. 打开或拖入图片
2. 选择标注工具(多边形/线段/矩形/点)
3. 选择类别(water/beach/boundary/dam)
4. 在图像上绘制标注
5. 点击"导出切片"保存训练样本

### 模型训练

1. 在"标记分割"中导出训练数据
2. 切换到"模型训练"标签页
3. 点击"选择数据目录"，选择包含分类子目录的数据集
4. 设置训练轮数
5. 点击"开始训练"
6. 训练完成后在识别标签页加载模型

### 识别流程

1. 加载训练好的模型(.pt文件)
2. 打开待识别的图片
3. 设置切片尺寸(24-128)和步长
4. 点击"运行识别"
5. 查看带彩色叠加的结果图
6. 保存结果

## 识别结果说明

识别结果使用彩色叠加显示各类别:
- **水面(water)**: 蓝色 (0, 200, 255)
- **滩面(beach)**: 绿色 (200, 255, 0)
- **分界线(boundary)**: 紫色 (255, 0, 255)
- **坝体(dam)**: 橙色 (255, 100, 0)
